sdl3-kotlin
===========

[![Build](https://github.com/technoir-lab/sdl3-kotlin/actions/workflows/ci.yaml/badge.svg?branch=main)](https://github.com/technoir-lab/sdl3-kotlin/actions/workflows/ci.yaml)
[![Maven Central Version](https://img.shields.io/maven-central/v/io.technoirlab.sdl3/sdl3)](https://central.sonatype.com/artifact/io.technoirlab.sdl3/sdl3)

[SDL3](https://github.com/libsdl-org/SDL) bindings for Kotlin Multiplatform.

## Usage

Add sdl3-kotlin dependency to your KMP project:

```kotlin
kotlin {
   sourceSets.commonMain {
       dependencies {
           implementation("io.technoirlab.sdl3:sdl3:<latest version>")
       }
   }
}
```

The bindings are generated by Kotlin/Native C interop in the `io.technoirlab.sdl3` package. They cover
`SDL.h` and `SDL_main.h` on every target, plus `SDL_metal.h` on Apple targets and `SDL_vulkan.h` on the
others. SDL is linked statically into the published bindings, so consumers need neither CMake nor an SDL
installation.

## Supported targets
* androidNativeArm64
* iosArm64
* iosSimulatorArm64
* linuxArm64
* linuxX64
* macosArm64
* mingwX64
* tvosArm64
* tvosSimulatorArm64

## Known limitations

* `mingwX64`: SDL GPU and the Direct3D 12 renderer are disabled because the Kotlin/Native MinGW
  toolchain lacks the required Direct3D 12 headers.
* `linuxArm64` and `linuxX64`: SDL includes only its offscreen and dummy video drivers and its disk
  and dummy audio drivers because the Kotlin/Native Linux sysroot lacks X11, Wayland, and audio
  development headers.
