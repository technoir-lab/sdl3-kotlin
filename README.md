sdl3-kotlin
===========

[![Build](https://github.com/technoir-lab/sdl3-kotlin/actions/workflows/ci.yaml/badge.svg?branch=main)](https://github.com/technoir-lab/sdl3-kotlin/actions/workflows/ci.yaml)
[![Maven Central Version](https://img.shields.io/maven-central/v/io.technoirlab.sdl3/sdl3)](https://central.sonatype.com/artifact/io.technoirlab.sdl3/sdl3)

[SDL 3.4.18](https://github.com/libsdl-org/SDL/releases/tag/release-3.4.18) bindings for Kotlin Multiplatform.

## Usage

Add sdl3-kotlin dependency to your KMP project:

```kotlin
kotlin {
   sourceSets.commonMain {
       dependencies {
           implementation("io.technoirlab.sdl3:sdl3:<latest version>")
       }
   }
}
```

The bindings are generated by Kotlin/Native C interop in the `io.technoirlab.sdl3` package. They cover
`SDL.h` and `SDL_main.h` on every target, plus `SDL_metal.h` on Apple targets and `SDL_vulkan.h` on the
others. SDL is linked statically into the published bindings, so consumers need neither CMake nor an SDL
installation. See the [sample](sample) project for a minimal application.

## Supported targets
* androidNativeArm64
* iosArm64
* iosSimulatorArm64
* linuxArm64
* linuxX64
* macosArm64
* mingwX64
* tvosArm64
* tvosSimulatorArm64

## Building from source

Initialize the pinned SDL source submodule, then build SDL and the bindings for every target:

```shell
git submodule update --init --recursive
make build
```

Run `make help` to list the other development tasks.

Install CMake 3.29 or newer on `PATH`; Windows hosts also need Ninja. Apple targets
require macOS and Xcode with the corresponding platform SDKs. Gradle runs `cmake` from
the Gradle daemon's `PATH`, so a daemon started by an IDE launched from the macOS Dock
may not find a Homebrew installation.

The [`io.technoirlab.cmake-import`](https://github.com/technoir-lab/kmp-gradle-plugins/tree/main/cmake-import-gradle-plugin)
plugin builds the `SDL3-static` target for each Kotlin/Native target using Kotlin/Native's
toolchain. It installs the headers and static archive under `sdl3/build/outputs/cmake/` and
generates the C-interop definitions under `sdl3/build/generated/cmake/`.

To build and test only the macOS bindings:

```shell
./gradlew :sdl3:macosArm64Test :sample:linkDebugExecutableMacosArm64
```

MinGW builds disable SDL GPU and the Direct3D 12 renderer because the
Kotlin/Native MinGW toolchain lacks the required Direct3D 12 headers.
The Kotlin/Native Linux sysroot lacks X11, Wayland, and audio development headers,
so Linux builds include only SDL's offscreen and dummy video drivers and its disk
and dummy audio drivers.
